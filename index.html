How the AI works

Nine agents behind one orchestrator (LangGraph + Gemini), each with one job.

🛡️ The core rule: AI never touches money. Every agent can only produce a draft. Nothing is saved, sent or paid until you confirm, and Fin never holds a rupee.
  • No invented data. Any person or amount the AI can't trace back to your words is removed and turned into a question.
  • One write path. AI drafts are re-checked with the same rules as an expense typed by hand.
  • Prompt-injection defence. Text from users, receipts and friends is treated as data, never as instructions.
  • Isolated insights. AI-written queries run in a throwaway database holding only your own rows, read-only.
  • Works offline. Every agent has a rule-based fallback for when the model is unavailable.
  • Deterministic where it matters. Settle-up and payment safety checks give the same answer every time.
